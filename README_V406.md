# Lofthus Road Open V406

Kvalitetsrunde etter V405.

- Rivalradar `Sesong` heter nå `Spilleroversikt`.
- `Odds` ligger ikke i Rivalradar; før-sesongmarkedet ligger under Ligaen som `Odds før sesongstart`.
- Før en ny måned har fått poeng, viser månedsfeltet forrige ferdige måned i stedet for en alfabetisk nulltabell.
- `Siste runde` skriver `poeng`, ikke bare `p`.
- Kapteinsoversikten har en flytende fullvisning som ikke blåser opp hele siden.
- Triple Captain telles ikke dobbelt som både vanlig C og TC i visningen.
- Rivalradar viser navnene på rivalene som faktisk eier en kandidat.
- Snakkiser prioriterer Triple Captain-hendelser og viser poengutfallet, inkludert 0-poengere.

Deploy alle kildefilene i repo-roten. Behold eksisterende `data/` urørt.
