# Lofthus Road Open V705

Hotfix for managerprofilens Form-seksjon under en aktiv gameweek.

## Fikset
- Aktiv GW bruker nå samme livepoeng som managerprofilens toppkort og ligatabellen.
- FPLs trege/statiske `entry/{id}/history` får ikke lenger lov til å vise 0 poeng i pågående GW når manageren faktisk har livepoeng.
- Aktiv GW får live rundeposisjon og live sammenlagtplassering.
- Tidligere GW-er bruker fortsatt offisiell historikk.
- Den aktive raden merkes med `· live`.

Bygger videre på V704.
