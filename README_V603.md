# Lofthus Road Open V603

Front-page editorial hotfix built on V602.

## What changed
- Removed the oversized front-page hero composition entirely.
- Replaced it with a compact three-part scoreline: league leader, previous GW winner, current/last month leader/winner.
- Moved the two core tables (Topp 5 and monthly table) directly below the scoreline. They are now the front-page lead.
- Moved Snakkiser directly below the two tables and kept them as a clean editorial list, not cards.
- Added a compact Top 3 "Mest populære" player list beside Snakkiser on desktop.
- Live content and Mitt Lofthus are now secondary and appear after the front-page news/data area.
- Preserved the V602 Hall of Fame ranking fix: season titles first, then other golds, then silvers, then bronzes.

## Deploy
Upload all files in this folder to the repository root and overwrite files with the same names. Keep the existing `data/` directory unchanged.
